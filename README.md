# Buzz plugins

Plugins for [Buzz](https://github.com/block/buzz-app), by Gus.

| Plugin | What it does |
| --- | --- |
| [Chat Cards](chat-cards) | Shows Chat SDK and json-render agent cards (tables, charts, buttons) in messages |

| Package | What it does |
| --- | --- |
| [chat-adapter-buzz](chat-adapter-buzz) | Chat SDK adapter: bots that answer in Buzz channels and post cards for Chat Cards |

Load a plugin in Buzz with **Settings → Plugins → Load from folder** and choose its folder.
